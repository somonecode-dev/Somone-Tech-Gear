# 🛒 SOMONE.GEAR - E-Commerce Platform

> Une plateforme e-commerce moderne et responsive conçue pour les équipements tech, accessoires de bureau et périphériques pour développeurs.

---

## 🌟 Fonctionnalités Clés

- 🌓 **Thème Sombre / Clair** : Basculement fluide avec prise en compte du contraste et persistance.
- 🛍️ **Gestion du Panier** : Ajout, modification des quantités, calcul dynamique des totaux et sauvegarde dans le localStorage.
- ❤️ **Liste de Favoris (Wishlist)** : Ajout instantané aux coups de cœur et synchronisation avec les badges du header.
- 🔍 **Recherche & Filtres** : Recherche dynamique par mot-clé et filtrage par catégories sur le catalogue produit.
- 🔍 **Aperçu Rapide (Quick View)** : Modale interactive pour explorer la galerie d'images et les détails d'un produit.
- 📱 **Design Mobile-First** : Navigation fluide avec menu hamburger responsive.

---

## 🛠️ Stack Technique

- **Frontend** : HTML5, CSS3 (Variables CSS, Flexbox, CSS Grid)
- **JavaScript** : Vanilla JS (ES6+)
- **Stockage** : LocalStorage (Gestion d'état persistant)

---

## 🚀 Installation & Utilisation

1. Cloner le dépôt :
   git clone [https://github.com/somonecode-dev/Somone-Tech-Gear.git](https://github.com/somonecode-dev/Somone-Tech-Gear.git)
